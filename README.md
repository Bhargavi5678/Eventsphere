# 📖 Overview

EventSphere is a full-stack event planning and management platform that enables organizers to manage events, guests, tickets, vendors, budgets, schedules, and analytics from a single dashboard.

The platform is designed for companies, colleges, wedding planners, event organizers, and individuals who want a complete solution for managing events efficiently.

- Automate attendee management
- Manage vendors efficiently

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Bhargavi5678/Eventsphere.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
